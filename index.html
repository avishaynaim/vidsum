Mobile access is enabled on this private Wi-Fi/LAN. Install the unpacked extension from kiwi-extension, then paste this private pairing URL into its options.

Keep the pairing URL private. Never forward the helper port through your router or use it on public Wi-Fi.

How it works

Long transcripts are split into ~20,000-character chunks, summarized separately, then merged. Each stage rotates to the next provider and resumes from its saved checkpoint.

Up to four videos run at once, one in-flight generation per provider, 2s between starts. Each video keeps its own tab.

Existing drafts are never overwritten. If a login or Cloudflare check appears, complete it in that browser window.

A usage cap pauses new dispatch without cancelling running work. Saved progress is kept.

Privacy and shutdown

Keep the bookmark private: it holds a local authorization token. Transcripts stay in memory except Full results you requested. Job metadata, links and the browser profile are stored locally only.
